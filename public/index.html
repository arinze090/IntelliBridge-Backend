API Reference v1

Welcome to the official REST API for Legacy Bridge Publishing. All endpoints respond with standard JSON. Write operations require a Bearer token.

List All Users Admin Only

GET /api/users

Requires Admin. Returns all registered users. Sensitive OTP fields are excluded.

Headers

Authorization string Required. Bearer {adminToken}
Example Response (200 OK)
[
  {
    "_id": "699ed17d5...",
    "fullname": "John Doe",
    "email": "john@example.com",
    "username": "johndoe",
    "isAdmin": false,
    "isVerified": true,
    "isSuspended": false
  }
]

Get User by ID Admin Only

GET /api/users/:id

Requires Admin. Returns a single user by their MongoDB ID.

Example Response (200 OK)
{
  "_id": "699ed17d5...",
  "fullname": "John Doe",
  "email": "john@example.com",
  "isAdmin": false,
  "isVerified": true,
  "isSuspended": false
}

Toggle Admin Status Admin Only

PUT /api/users/:id/admin

Requires Admin. Grant or revoke admin privileges for a user.

Body Parameters

isAdmin boolean Required. true to grant admin, false to revoke.
Example Request
{ "isAdmin": true }
Example Response (200 OK)
{
  "_id": "699ed17d5...",
  "fullname": "John Doe",
  "email": "john@example.com",
  "isAdmin": true
}

Suspend / Reactivate User Admin Only

PUT /api/users/:id/suspend

Requires Admin. Suspend or reactivate a user account. Suspended users cannot log in and will see a clear error message directing them to contact the technical team. Admins cannot be suspended.

Body Parameters

isSuspended boolean Required. true to suspend, false to reactivate.
Example Request (Suspend)
{ "isSuspended": true }
Example Response (200 OK)
{
  "_id": "699ed17d5...",
  "fullname": "John Doe",
  "email": "john@example.com",
  "isSuspended": true,
  "message": "User account has been suspended"
}
Login Response for Suspended User (403)
{
  "message": "Your account has been suspended. Please contact the technical team for assistance."
}

Register new user

POST /api/auth/signup

Register a new user account. Returns a JWT token upon successful creation.

Body Parameters

fullname string Required. Full name of the user.
email string Required. User's unique email address.
username string Required. Unique username.
password string Required. Minimum 8 characters, containing uppercase, lowercase, numbers, and symbols.
Example Request
{
  "fullname": "Jane Doe",
  "email": "jane@example.com",
  "username": "janedoe",
  "password": "P@ssw0rd123!"
}
Example Response (201 Created)
{
  "_id": "64f1e9c...",
  "fullname": "Jane Doe",
  "email": "jane@example.com",
  "username": "janedoe",
  "token": "eyJhbGciOiJIUzI1NiIsIn..."
}

Login user

POST /api/auth/login

Authenticate an existing user and return a JWT token. Can use either username or email.

Body Parameters

email string Required if username is not provided.
username string Required if email is not provided.
password string Required user password.
Example Request
{
  "email": "test@example.com",
  "password": "P@ssw0rd123!"
}
Example Response (200 OK)
{
  "_id": "64f1e9c...",
  "fullname": "John Doe",
  "token": "eyJhbGciOiJIUzI1NiIsIn..."
}

Forgot Password

POST /api/auth/forgotpassword

Sends a 6-digit OTP to the user's email address if registered.

Body Parameters

email string Required. Registered user email address.
Example Request
{
  "email": "test@example.com"
}
Example Response (200 OK)
{
  "message": "OTP sent to email"
}

Reset Password

PUT /api/auth/resetpassword

Resets the user's password using the OTP and returns a new JWT token.

Body Parameters

email string Required. The user's email address.
otp string Required. The 6-digit OTP sent to the email.
newPassword string Required. New strong password string.
Example Request
{
  "email": "test@example.com",
  "otp": "123456",
  "newPassword": "NewP@ssw0rd!"
}
Example Response (200 OK)
{
  "message": "Password reset successfully",
  "_id": "64f1e9c...",
  "token": "eyJhbGciOiJIUzI1NiIsIn..."
}

Verify Email

POST /api/auth/verify-email

Verifies a new user's email address using the 6-digit OTP sent during signup.

Body Parameters

email string Required. The user's email address.
otp string Required. The 6-digit OTP sent to the email.
Example Request
{
  "email": "test@example.com",
  "otp": "123456"
}
Example Response (200 OK)
{
  "message": "Email verified successfully"
}

Resend Verification OTP

POST /api/auth/resend-verification

Generates and sends a new 6-digit verification code to the user's email.

Body Parameters

email string Required. Registered user email address.
Example Request
{
  "email": "test@example.com"
}
Example Response (200 OK)
{
  "message": "Verification OTP sent to email"
}

Deactivate Account

POST /api/auth/deactivate

Requires Auth. Soft-deletes user account, appending a timestamp to their existing email and username so that they can register with it again later. Rejects any previously issued JWT tokens.

Headers

Authorization string Required. Bearer {token}

Body Parameters

password string Required. Current password to confirm deactivation.
Example Request
{
  "password": "P@ssw0rd123!"
}
Example Response (200 OK)
{
  "message": "Account has been deactivated successfully"
}

Update Profile

PUT /api/auth/profile

Requires Auth. Edit user profile details. Currently enables updating the username and profile picture.

Headers

Authorization string Required. Bearer {token}

Body Parameters

username string Optional. New unique username.
profilePicture string Optional. URL to the uploaded profile picture.
profilePictureId string Optional. Standardized Cloudinary unique ID for the image.
Example Request
{
  "username": "newCoolUsername",
  "profilePicture": "http://example.com/avatar.jpg",
  "profilePictureId": "avatars/1239129412"
}
Example Response (200 OK)
{
  "_id": "64f1e9c...",
  "fullname": "Test User",
  "email": "user@example.com",
  "username": "newCoolUsername",
  "profilePicture": "http://example.com/avatar.jpg",
  "profilePictureId": "avatars/1239129412"
}

List Categories

GET /api/categories

Fetches a list of all active categories. Sorts alphabetically by name.

Query Parameters (Admin Only)

includeDeleted boolean Set to "true" to include soft-deleted categories. Requires Admin token.
Example Response (200 OK)
[
  {
    "_id": "699ed17b5...",
    "name": "Science Fiction",
    "description": "Sci-Fi books",
    "isDeleted": false
  }
]

POST /api/categories

Body Parameters

name string Required. The category name.
description string Optional.
Example Request
{

  "description": "Books with magic"
}
Example Response (201 Created)
{
  "_id": "699ed17c...",
  "name": "Fantasy",
  "description": "Books with magic"
}

Requires Admin privileges. Modifies an existing category.

{

}

Fetches a list of all active books in the library. Automatically populates category data.

Query Parameters (Admin Only)

includeDeleted boolean Set to "true" to include soft-deleted books in the response array. Requires Admin token.
Example Response (200 OK)
[
  {
    "_id": "699ed17d5...",
    "bookTitle": "Dune",
    "price": 15.99,
    "bookImageId": "books/dune_cover_123",
    "isDeleted": false,
    "category": {
      "_id": "699ed17b5...",
      "name": "Science Fiction"
    }
  }
]

Create Book Admin Only

POST /api/books

Requires Admin privileges. Creates a new book in the library.

Body Parameters

bookTitle string Required. The title of the book.
author string Required.
aboutAuthor string Required.
description string Required. Summary of the book.
price number Required. Must be >= 0.
bookImage string Required. URL to cover image.
bookImageId string Required. Cloudinary public ID for the image.
bookUrl string Required. URL to the book content/file.
bookFormat string Required. (e.g., PDF, EPUB, Physical)
category string Optional. Category ObjectId.
Example Request
{
  "bookTitle": "Dune",
  "author": "Frank Herbert",
  "aboutAuthor": "He wrote Dune.",
  "description": "A book about sand.",
  "price": 15.99,
  "bookImage": "http://example.com/dune.jpg",
  "bookImageId": "books/dune_cover_123",
  "bookUrl": "http://example.com/dune.epub",
  "bookFormat": "EPUB",
  "category": "699ed17b5eda62697780e3d8"
}

Checkout

POST /api/orders/checkout

Requires Auth. Verify payment and create an order, automatically granting books to the user's library and sending a receipt email.

Headers

Authorization string Required. Bearer {token}

Body Parameters

paymentMethod string Required. e.g. "paystack"
items array Required. Array of Book Object IDs
transactionReference string Required. Valid reference from the payment gateway
paymentData object Optional. Full response from payment gateway
Example Request
{
  "paymentMethod": "paystack",
  "items": ["69bffd64b1e9067a1c36b9cb"],
  "transactionReference": "ref_1773768426280"
}
Example Response (201 Created)
{
  "message": "Purchase successful! Books added to your library.",
  "order": { ... }
}

List All Orders Admin Only

GET /api/orders

Requires Admin privileges. Returns a paginated list of all orders across the platform.

Query Parameters

page number Page number (default: 1)
limit number Results per page (default: 20)
status string Filter by status (e.g. pending, completed, failed)
Example Request
GET /api/orders?page=1&status=completed
Example Response (200 OK)
{
  "orders": [...],
  "page": 1,
  "totalPages": 5,
  "totalOrders": 98
}

Delete User Test Use Only

DEL /api/users/:id

⚠️ This is a completely unrestricted testing endpoint. It requires no authentication and no admin token. It will be disabled in the production environment. Do not use for anything other than clearing test data.

Example Response (200 OK)
{
  "message": "User deleted successfully"
}
